# Стопка

Расширение для YouTube: в углу каждого превью — кнопка **＋**, нажимаешь, видео попадает в список. Такая же кнопка стоит рядом с заголовком открытого видео. Из значка расширения список открывается: можно найти нужное, скопировать все ссылки разом или удалить лишнее.

Работает на главной, в поиске, в рекомендациях рядом с видео, на полке шортсов, в плейлистах и на страницах каналов. Тёмная и светлая тема — по настройке YouTube и системы.

Один код для Chrome, Edge и Safari — все понимают Manifest V3 и Web Extensions API. Без сборки, без зависимостей, без сети: расширение никуда не ходит и ничего не собирает.

## Что внутри

| Файл | Зачем |
|---|---|
| `manifest.json` | Описание расширения, права: `storage` + доступ к `*.youtube.com` |
| `content.js` | Ищет превью на странице, вешает кнопку, пишет в хранилище |
| `content.css` | Вид кнопки на превью |
| `popup.html/css/js` | Список, поиск, копирование, удаление |
| `icons/` | Иконки 16/32/48/128 |

Данные лежат в `chrome.storage.local` под ключом `items` — только на твоей машине, никуда не уходят. Формат записи:

```json
{ "id": "dQw4w9WgXcQ", "url": "https://www.youtube.com/watch?v=dQw4w9WgXcQ",
  "title": "Название", "channel": "Канал",
  "thumb": "https://i.ytimg.com/vi/dQw4w9WgXcQ/mqdefault.jpg", "addedAt": 1756000000000 }
```

## Установка в Chrome и Edge (30 секунд)

1. Скачать код: зелёная кнопка **Code → Download ZIP** на странице репозитория и распаковать — или `git clone`. Папку потом не удалять и не переносить: браузер читает файлы прямо из неё.
2. `chrome://extensions` (в Edge — `edge://extensions`) → включить **Режим разработчика**
3. **Загрузить распакованное расширение** → выбрать папку, в которой лежит `manifest.json`
4. Открыть YouTube, обновить вкладку

После правки файлов — кнопка «Обновить» на карточке расширения и F5 на вкладке YouTube.

## Установка в Safari на macOS

Safari не грузит папку с расширением напрямую — его нужно завернуть в приложение и подписать. Понадобятся Xcode и аккаунт [Apple Developer Program](https://developer.apple.com/programs/), добавленный в Xcode → Settings → Accounts.

```bash
./safari/build.sh
```

Скрипт сам найдёт твою команду разработчика в Xcode, соберёт приложение, подпишет его и поставит в `/Applications`. При первом запуске Xcode выпустит сертификат «Apple Development» и зарегистрирует Мак в аккаунте. Если команд в Xcode несколько — укажи нужную: `STOPKA_TEAM_ID=XXXXXXXXXX ./safari/build.sh`.

Дальше один раз в Safari: Настройки → **Расширения** → включить «Стопку», затем на youtube.com нажать её иконку → «Всегда разрешать на этом веб-сайте».

После пересборки перезапусти Safari (⌘Q): вкладки, открытые со старой версией, теряют связь с расширением, и ＋ в них не сохраняет.

Без Apple Developer Program, по документации Apple, расширение не подписывается сертификатом разработчика (бесплатную Personal Team скрипт не берёт, мы её не проверяли). Тогда остаётся способ из той же документации: Safari → Настройки → Разработчик → «Разрешить неподписанные расширения» и «Добавить временное расширение…» с этой папкой. Галка и временное расширение сбрасываются при каждом перезапуске Safari.

Снести: `./safari/uninstall.sh`

### Mac App Store

```bash
./safari/build.sh --app-store   # пакет в safari/dist/, подпись Apple Distribution
./safari/build.sh --upload      # то же, сразу в App Store Connect
```

Перед отправкой в App Store Connect должна быть создана запись приложения с bundle ID `com.stopka.youtube`. Тексты страницы — `safari/appstore/metadata.md` (лимиты проверяет `check-metadata.sh`), скриншоты — `safari/appstore/screenshots/`, пересобираются `shoot.py`. Политика конфиденциальности — [PRIVACY.md](PRIVACY.md).

## Если кнопка не появилась

YouTube периодически меняет вёрстку. Все селекторы вынесены наверх `content.js`:

- `ANCHOR_SELECTOR` — ссылка-превью, на которую вешается кнопка
- `CARD_SELECTOR` — карточка видео целиком (из неё берётся название и канал)
- `TITLE_SELECTOR`, `CHANNEL_SELECTOR` — где искать текст

Открой инспектор на превью, посмотри реальные классы и добавь их в нужный список через запятую. Остальной код трогать не надо.

## Куда развивать

- Синхронизация между устройствами: заменить `chrome.storage.local` на `chrome.storage.sync` (лимит ~100 КБ, хватит на пару тысяч ссылок)
- Теги или папки: добавить поле `tags` в запись и фильтр в попапе
- Горячая клавиша: `commands` в манифесте + обработчик в `content.js`
