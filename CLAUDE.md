# Стопка — расширение для браузера

Расширение к YouTube: кнопка «＋» на превью видео складывает ссылки в локальный список, попап показывает список, ищет по нему и копирует все ссылки разом.

Целевые браузеры: **Chrome** (основная разработка) и **Safari на macOS** (через `safari-web-extension-converter`). Код общий, Manifest V3.

## Правила проекта

- **Без сборки и без зависимостей.** Чистые HTML/CSS/JS, никакого npm, бандлеров, TypeScript и фреймворков. Файлы грузятся браузером как есть.
- **Без background/service worker.** Всё делают контент-скрипт и попап, оба обращаются к `chrome.storage.local` напрямую. Не добавлять service worker без явной необходимости — в Safari он ведёт себя иначе.
- **Права по минимуму.** Сейчас `storage`, `clipboardWrite` и хосты `*.youtube.com`. Любое новое право — сознательное решение, а не побочный эффект рефакторинга.
- **API — `chrome.*` с колбэками**, не `browser.*` и не промисы: так работает и в Chrome, и в Safari без полифилла.
- **Два языка: английский по умолчанию и русский.** Все строки интерфейса — в `_locales/en|ru/messages.json`, в коде только `t('ключ')` (`chrome.i18n.getMessage`), в `popup.html` — атрибуты `data-i18n`. Новая строка — сразу в оба файла. Язык выбирает браузер, переключателя нет. Тон: повелительное наклонение, без восклицаний; одно действие называется одинаково везде — «Add to stack» / «Отложить в стопку», «Remove from stack» / «Убрать из стопки». Имя: Stopka / «Стопка».
- **Никакой сети.** Расширение не ходит наружу и не собирает статистику. Превью подтягиваются по предсказуемому адресу `i.ytimg.com/vi/<id>/mqdefault.jpg`, без парсинга.

| Файл | Содержимое |

| `icons/` | 16/32/48/128 px |
| `PRIVACY.md` | Политика конфиденциальности (ссылка из App Store и из окна приложения) |

## Хранилище

`chrome.storage.local`, ключ `items` — массив, новые записи добавляются в начало (`unshift`). Дедупликация по `id`.

```json
{ "id": "dQw4w9WgXcQ", "url": "https://www.youtube.com/watch?v=dQw4w9WgXcQ",
  "title": "Название", "channel": "Канал",
  "thumb": "https://i.ytimg.com/vi/dQw4w9WgXcQ/mqdefault.jpg", "addedAt": 1756000000000 }
```

При изменении схемы — не ломать существующие записи: добавлять поля с дефолтом, а не переименовывать старые.

## Хрупкое место: селекторы YouTube

Вёрстка YouTube меняется без предупреждения. Все селекторы собраны константами вверху `content.js`:

- `ANCHOR_SELECTOR` — ссылка-превью, к ней прикрепляется кнопка
- `CARD_SELECTOR` — карточка видео целиком, из неё достаются название и канал
- `TITLE_SELECTOR`, `CHANNEL_SELECTOR` — где искать текст

Правило: новые варианты **добавлять** в список через запятую, а не заменять старые — на разных страницах (главная, поиск, сайдбар, шортсы, плейлист) живут разные разметки одновременно.

Кнопка лежит внутри `<a>`, поэтому её обработчики обязаны звать `preventDefault()` и `stopPropagation()` на `click`, `mousedown` и `pointerdown` — иначе YouTube уводит на видео.

## Как проверять

Автотестов нет, проверка ручная. После правок:

1. `chrome://extensions` → «Обновить» на карточке → F5 на вкладке YouTube.
2. Прогнать сценарии: главная, результаты поиска, страница видео (сайдбар с рекомендациями), полка шортсов, страница плейлиста, страница канала.
3. Проверить: кнопка видна на каждом превью, клик не уводит на видео, состояние «сохранено» переживает перезагрузку страницы, попап показывает то же самое, удаление из попапа снимает галочку на превью.
4. Тёмная тема попапа — через системную настройку macOS.

## Safari

Всё живёт в `safari/`, исходники расширения не дублируются:

| Файл | Зачем |
|---|---|
| `safari/build.sh` | Конвертация → наложение `safari/app/` → сборка и установка себе; `--app-store` / `--upload` — пакет для Mac App Store |
| `safari/uninstall.sh` | Удаление приложения; заодно чистит следы старого сторожа |
| `safari/app/` | Наши файлы контейнера поверх сгенерированных: окно `en/` и `ru/Main.html` со ссылкой на политику, `ru/InfoPlist.strings` (имя «Стопка»), `ru/menu.txt` (перевод меню), `localize.pl` (вписывает ru в проект), `ViewController.swift`, иконка (`make-icon.swift`) |
| `safari/appstore/` | Страница в App Store на en и ru: `metadata.md` + `check-metadata.sh`, скриншоты `screenshots/en|ru/` + `shoot.py` (безголовый Chromium из `~/.venvs/playwright`) |
| `safari/project/`, `safari/dist/` | Сгенерированный проект и пакеты, в git не входят |

```bash
./safari/build.sh   # после правок расширения; затем ⌘Q и снова открыть Safari
```

`build.sh` копирует в бандл только файлы расширения — `README.md`, `CLAUDE.md`
и сам `safari/` внутрь не попадают. Проект и папка сборки лежат вне исходников,
иначе Safari видит два одинаковых расширения.

### Подпись

Сборка подписывается командой разработчика из Xcode → Settings → Accounts
(`CODE_SIGN_STYLE=Automatic`, `-allowProvisioningUpdates`). С сертификатом
разработчика Safari грузит расширение сам — без «Разрешить неподписанные
расширения» (документация Apple, «Running your Safari web extension»).
Проверено 03.10.2026: Safari перезапущен без галки, «Стопка» в списке, ＋ сохраняет.

- **Team ID в репозиторий не пишем.** Скрипт берёт платную команду из настроек
  Xcode; при нескольких — `STOPKA_TEAM_ID`. После сборки сверяет
  `TeamIdentifier` у appex и падает, если подпись не та.
- **Встроенного профиля нет** — для приложения в песочнице без особых прав
  на macOS он не нужен, `codesign --verify --strict` проходит.
- **Раздавать другим** этот `.app` нельзя: сертификат «Apple Development» только
  для своих Маков. Для раздачи нужен Developer ID + нотаризация (`notarytool`,
  `stapler`) — не сделано, пароль для нотаризации пользователь хранит сам
  через `xcrun notarytool store-credentials`, в репозиторий он не попадает.

### Грабли, на которые уже наступили

- **ID приложения конвертер склеивает из префикса и имени** (`com.stopka.Stopka`,
  для кириллицы — `com.stopka.------`), а ID расширения берёт как есть — сборка
  падает на проверке префикса. `build.sh` выставляет ID приложения явно.
- **Приложение — `Stopka.app`, раньше было `Стопка.app`.** ID тот же; `build.sh`
  и `uninstall.sh` убирают старое приложение, иначе в Safari две «Стопки».
- **Русская локализация контейнера.** Конвертер даёт только en/Base. `build.sh`
  кладёт `ru.lproj` (окно, меню, имя), а `localize.pl` вписывает его в проект,
  разбирая pbxproj как plist (после этого проект в XML — Xcode это читает).
  Строки меню берутся из storyboard через `ibtool`; без перевода в `menu.txt`
  сборка падает, чтобы меню не вышло наполовину английским.
- **Открытые вкладки после пересборки.** Safari выгружает старую версию, а
  контент-скрипт в уже открытой вкладке остаётся без связи с ней: кнопки
  нарисованы, клик молча не сохраняет. Лечится перезапуском Safari (⌘Q).
- **Минимальная macOS.** Конвертер ставит приложению macOS по версии Xcode
  (27), расширению — 12. `build.sh` выравнивает обе цели на 12.0, иначе в App
  Store «Стопку» не поставить на macOS 26 и старше. На старых системах не проверено.
- **Контейнер правим наложением, а не в проекте.** Проект пересоздаётся каждый
  раз, поэтому всё своё лежит в `safari/app/`, а `build.sh` кладёт поверх и
  подставляет `__EXTENSION_BUNDLE_ID__` / `__PRIVACY_URL__`. В шапки
  сгенерированных Swift-файлов конвертер пишет имя пользователя Мака — в git
  они не попадают.
- **Номер сборки — время UTC** (`YYYYMMDD.HHMM`): App Store Connect требует,
  чтобы каждая отправка была с номером больше прежнего.
- **Скриншоты — макет, не реальный YouTube**: на настоящем были бы аккаунт
  пользователя и чужие превью. Кнопки и попап в макете настоящие.
- **Смена подписи = новое расширение для Safari.** Список видео обнуляется,
  включение и доступ к youtube.com надо дать заново.
- **До подписи был сторож** — LaunchAgent и AppleScript, которые после каждого
  запуска Safari кликали «Разрешить неподписанные расширения». С подписью не
  нужен и удалён; `uninstall.sh` убирает его следы, если остались.

## Что дальше по плану

- Синхронизация между устройствами: `chrome.storage.local` → `chrome.storage.sync` (лимит ~100 КБ; понадобится урезать поля `title`/`thumb` или хранить только `id`)
- Теги или папки: поле `tags` в записи + фильтр в попапе
- Горячая клавиша: секция `commands` в манифесте + обработчик в `content.js`
- Пункт в контекстном меню для правого клика по любой ссылке на видео (потребует service worker и право `contextMenus`)
